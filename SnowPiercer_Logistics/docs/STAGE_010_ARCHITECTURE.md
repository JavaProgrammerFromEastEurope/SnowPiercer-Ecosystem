# LOG-CORE-010 architecture
Opt-in IsolatedLogisticsService subclasses ClientBoundLogisticsService. Before creating sockets it checks IsolationPolicy and existing filesystem ownership/mode for three isolated roots. No privileged accounts are created and no filesystem permissions are modified by this layer. Legacy LogisticsLedger remains callable for backward compatibility; isolation must be supplied by a privileged OS installer and independently verified. Kernel peer credentials in prior stages identify the direct socket peer, but permit authority still trusts the service's reported original client UID. No cryptographic client-origin attestation has been added.
