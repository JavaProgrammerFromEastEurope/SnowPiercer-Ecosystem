# LOG-CORE-014 Architecture
Opt-in test-only `four_uid_ipc_probe(IsolationPolicy)` spawns three isolated AF_UNIX servers using setgroups/setgid/setuid, in disposable /tmp directories. Client subprocesses connect under the approved or deliberately incorrect UID; servers inspect SO_PEERCRED and return decision. Servers use deliberately permissive socket permissions for reachability in this TEST HARNESS only, not a production template. Server protocols are synthetic and do not invoke the actual ledger, permit authority, or witness. Production admission always fails closed. Existing legacy classes are still importable for compatibility and are NOT OS-fenced by this Stage.
