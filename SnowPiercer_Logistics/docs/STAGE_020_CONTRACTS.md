# Contracts

ProductionIdentityPolicy.validate(): requires four distinct positive non-root integer UIDs; the current process must have service_uid and SO_PEERCRED must be available.
verify_endpoint(path,uid): lstat final component; require socket inode, expected owner and no world-write; returns dev/inode; not a race-free live peer authentication.
MandatoryProductionLogisticsService.start(): always raises AdmissionError NO-GO, never publishes a listener.
crash_state_matrix(anchor): returns six classification labels; no mutation or fault injection.
production_admission(): always raises AdmissionError.
