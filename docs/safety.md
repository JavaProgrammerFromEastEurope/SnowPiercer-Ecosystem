# Preliminary safety analysis

Hazard inventory in `safety/hazards.json` is a starting PHA. Severity is a screening assumption, not a verified risk rating. Probability, detectability, residual risk, ALARP and independent assurance are not established.

Deployment gate is BLOCKED/NO-GO until site investigations, engineering calculations, applicable code compliance, safety case, regulatory approvals, integration evidence and independent review are obtained. Automated tests check only artifact consistency, not physical safety.
