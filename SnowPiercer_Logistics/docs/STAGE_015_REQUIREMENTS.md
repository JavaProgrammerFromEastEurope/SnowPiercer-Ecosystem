# LOG-CORE-015 Requirements
- R15-01 Preserve all legacy public library APIs and cumulative regression.
- R15-02 Issue a scope- and client-UID-bound, 256-bit bearer permit only to kernel-authenticated operator.
- R15-03 Require direct kernel-authenticated client presentation to independent authority before consumption.
- R15-04 Consume atomically once, only from kernel-authenticated service UID.
- R15-05 Reject invalid UID, scope, replay, missing attestation and legacy authority protocol.
- R15-06 Require independently verified four-UID ledger/witness/authority E2E before production admission (NOT SATISFIED).
