# LOG-CORE-002 Contracts
`SecureLogisticsService(root, uid_roles, timeout=2.0).start()/stop()` owns local Unix socket and SQLite ledger. `request(socket_path, action, args, timeout)` returns `{ok: bool, result: ...}` or `{ok: false, error: ..., message: ...}`. `uid_roles` must be provisioned by a trusted service operator. Actions: verify, get_cargo, issue_permit, recover, add_container, add_location, register_cargo, create_mission, record_transfer, transition_cargo, transition_mission. `issue_permit` requires admin; `recover` consumes matching UID-bound permit once, but DOES NOT repair a divergent checkpoint. Service startup checks checkpoint and SQLite integrity. `Principal` in legacy API remains caller-provided and must be restricted to trusted in-process use.
