# Architecture
Unix-domain socket admission uses kernel peer credentials and configured UID-to-role mapping. The server retains a nonblocking flock on service.lock for its full lifetime. A SQLite ledger, phase journal and local checkpoint form the existing recovery state machine. IPC dispatch checks filesystem metadata before commands. This is a same-host prototype, NOT a production isolation boundary. The SQLite database remains accessible to a process with the service UID. Local checkpoint and phase journal can be rolled back together by an attacker with write access. A separate witness service and privilege-separated storage are required.
